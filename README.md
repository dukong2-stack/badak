# 바닥 신호

코스피 시가총액 400위 안의 대형·중형·준중형주에서 바닥 신호를 점수(100점)와 단계(① 과매도 → ② 바닥 형성 → ③ 전환 확인)로 보여주는 웹앱입니다. 평일 저녁 GitHub Actions가 자료를 모아 채점하고, GitHub Pages가 화면을 띄웁니다.

## 처음 설정 (PC에서 한 번)

1. GitHub에 새 저장소 `badak`을 만들고(Public), 이 폴더의 파일을 모두 올립니다. `.github` 폴더와 `.nojekyll` 파일도 꼭 함께 올립니다.
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 세 개를 추가합니다. 값은 증시 온도계·배당가치 노트에 넣은 것과 같습니다.
   - `DART_API_KEY`: OpenDART 인증키
   - `KRX_ID`, `KRX_PW`: 한국거래소 정보데이터시스템 로그인
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
4. **Actions → 바닥 신호 수집 → Run workflow**로 첫 수집을 돌립니다. 첫 회는 5년치 PER·PBR 이력과 1년치 공시를 모으느라 30~60분쯤 걸립니다. 이후에는 매일 10분 안팎입니다.
5. 끝나면 `https://dukong2-stack.github.io/badak/` 를 폰 크롬에서 열고 메뉴의 **앱 설치(홈 화면에 추가)**를 누릅니다.

첫 회가 시간 제한이나 DART 한도로 중간에 멈춰도, 모은 자료는 캐시에 저장되므로 다시 실행하면 이어서 진행합니다.

## 자동 실행

평일 19:40(한국시간)에 돌아갑니다. GitHub 사정으로 수십 분 늦어질 수 있습니다. 공매도 잔고는 거래소가 이틀 뒤 공표하므로 이틀 전 값을 씁니다.

## 기준 바꾸기

`config.json`의 숫자만 고치면 다음 수집부터 반영됩니다.

- `weights`: 세부 항목 배점(합계 100). A 매도 소진, B 과매도·다이버전스, C 바닥 패턴·전환, D 수급, E 가치 바닥, F 내부자·자사주, G 실적 바닥
- `penalties`: 감점(증자·메자닌, 주요주주 매도, 횡령·배임·소송)과 감점 한도
- `universe`: 시총 순위 범위, 최소 거래대금(억원), 3년 중 흑자 연수, 이자보상배율 기준
- `valid_days`: 기술적 신호의 유효기간(거래일)

## 자료 출처

- 네이버 증권: 시가총액 순위, 일봉(수정주가), 관리·거래정지·투자경고·투자위험 종목
- 한국거래소(pykrx): 외국인·기관 순매수, 외국인 지분율, 공매도 잔고, PER·PBR·배당수익률 이력
- OpenDART: 감사의견, 재무(흑자·자본잠식·이자비용), 분기 영업이익, 주요사항·거래소 공시, 임원·주요주주 소유 보고

## 알아둘 점

- 종목별 신용잔고는 공개 출처를 찾지 못해 '미수집'(0점)으로 둡니다. 그래서 실제 최고점은 95점입니다.
- '임원·주요주주 지분 증가'는 소유상황 보고의 증감 수량 기준이라 장내매수 외에 신규 선임·주식보상도 섞일 수 있습니다. 상세 화면의 DART 링크로 확인하세요.
- 이자보상배율은 손익계산서의 이자비용을 우선 쓰고, 없으면 현금흐름표의 이자 지급액, 그것도 없으면 금융원가로 계산합니다(기준 탭 제외 사유에 어떤 값을 썼는지 표시).
- 오른쪽 위 시장 표시는 같은 계정의 증시 온도계(`heatmeter`) 자료를 읽어 과열·냉각 지표 수를 보여줍니다. 점수에는 넣지 않습니다.
- 점수는 바닥 가능성을 거르는 도구이며 매수 추천이 아닙니다.
